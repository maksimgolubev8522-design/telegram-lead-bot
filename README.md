## 🎯 Что делает бот

Бот решает типичную бизнес-задачу: **автоматический сбор заявок от клиентов 24/7**.

**Без бота:** владелец бизнеса теряет клиентов, когда не успевает ответить на сообщения.  
**С ботом:** все заявки автоматически собираются в таблицу, ни один клиент не потерян.

### Возможности:
- ✅ Работает круглосуточно без участия человека
- ✅ Задает структурированные вопросы (Имя, Телефон, Услуга)
- ✅ Сохраняет все данные в Excel-файл
- ✅ Отправляет подтверждение клиенту
- ✅ Валидирует данные (проверяет, что телефон содержит цифры)
- ✅ Безопасно хранит токен через переменные окружения

## 🚀 Как использовать

### 1. Установка зависимостей

```bash
pip install pyTelegramBotAPI pandas openpyxl python-dotenv
```
### 2. Создание бота
Откройте Telegram и найдите @BotFather
Отправьте команду /newbot
Придумайте имя и username для бота
Скопируйте полученный токен

### 3. Настройка токена
Создайте в корне проекта файл .env и добавьте в него:
'BOT_TOKEN=ваш_токен_от_BotFather'

⚠️ Важно: файл .env уже добавлен в .gitignore и не попадает на GitHub. Это обеспечивает безопасность вашего токена.

### 4. Запуск
```bash
python main.py
```

### 5. Результат
Бот запустится и начнет принимать заявки. Все данные автоматически сохраняются в файл leads.xlsx.

### 🛠 Технологии
Python 3.10+
pyTelegramBotAPI — работа с Telegram Bot API
Pandas — работа с таблицами
OpenPyXL — чтение/запись Excel
python-dotenv — безопасное хранение токенов

### 💼 Кейс из практики
Задача: Владелец салона красоты терял клиентов из-за того, что не успевал отвечать на сообщения в мессенджерах. Заявки просто терялись в переписке.
Решение: Разработал Telegram-бота, который:
Автоматически принимает заявки 24/7
Задает структурированные вопросы (имя, телефон, услуга)
Сохраняет все данные в Excel-таблицу
Отправляет подтверждение клиенту

### Результат:
📱 Бот работает круглосуточно без участия владельца
📊 Все заявки в одной таблице — легко анализировать
✅ 0 потерянных клиентов
💰 Окупаемость — менее 1 недели
🔒 Безопасность
Токен бота хранится в файле .env, который не загружается на GitHub (благодаря .gitignore). Это стандартная практика для защиты секретных данных.
